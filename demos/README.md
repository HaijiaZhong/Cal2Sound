# Reconstruction Demos

Future representative reconstruction examples will include original audio,
reconstructed audio, F0 trajectories, and pitch reconstruction metrics.

Suggested organization:

- `original/`: original audio.
- `reconstructed/`: reconstructed audio.
- `figures/`: F0 trajectories and associated visualizations.

No examples or metrics are included. Sharing permissions must be confirmed
before release. Empty `.gitkeep` files preserve the directories in Git.
