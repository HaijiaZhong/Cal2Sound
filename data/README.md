# Data

The raw wide-field calcium imaging dataset is not included in the repository at this stage.

Dataset access, licensing, preprocessing, and input formats are TBD. Public
availability is not assumed. Future additions may include preprocessing code,
model implementation, evaluation code, and representative reconstruction examples,
subject to the relevant sharing permissions.

Local data can later be placed in `raw/` and `processed/`, which are ignored by
Git. Use relative paths in configuration rather than server-specific locations.
